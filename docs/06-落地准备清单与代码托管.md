# 06 · 落地准备清单与代码托管

## 0. 一句话时间线

```
Day 0   注册小程序拿 AppID ──┬── 提交 ICP 备案（1~20 工作日，唯一长阻塞）
                            ├── 提交用户隐私保护指引（1~3 工作日）
                            └── 建代码仓库 + 开通云开发
Day 0~14 并行开发（体验版可正常调试，不受备案影响）
Day N   备案通过 → 提审（1~7 天）→ 发布
```

**关键**：小程序备案是**提审前的阻塞项，不是开发的阻塞项**。拿到 AppID 就能开发，体验版、真机调试、云开发全都不受影响。所以别等备案，先开工。

## 2. 代码托管：先看项目归属

这个选择取决于**项目归谁**，选错了后面有合规麻烦，所以放在第一位判断。

### ⚠️ 先回答一个问题：这个小程序是公司项目，还是个人/团队创业项目？

| 项目归属 | 推荐托管 | 理由 |
|----------|----------|------|
| **公司内部项目** | **工蜂 `git.woa.com`** | 内网合规、蓝盾 CI 可直接打通、免费无限私有仓、与你现有 `kairos/*` 仓库习惯一致 |
| **个人 / 团队创业项目** | **腾讯云 CODING** 或 **Gitee** | 公网可访问、协作者无内网限制、代码归属清晰 |

> **重要提醒**：如果是个人/创业项目，**不要**用工蜂、蓝盾或公司内网机器。代码落在公司仓库里，后续归属和商业化都会说不清。反过来，如果是公司项目，**不要**放 GitHub / Gitee 公有仓——腾讯对代码外放有明确合规要求。

### 方案对比

| 维度 | 工蜂 git.woa.com | 腾讯云 CODING | Gitee | GitHub |
|------|------------------|---------------|-------|--------|
| 适用 | 公司内部项目 | 创业/对外，需 CI | 创业/轻量 | 不推荐 |
| 访问 | 需办公网 / VPN | 公网 | 公网 | 国内访问不稳 |
| CI/CD | **蓝盾**（你已熟悉） | 内置 CODING CI | 较弱 | Actions 好用但有合规风险 |
| 与云开发集成 | 需自建 | **原生集成** | 需自建 | 需自建 |
| 私有仓成本 | 免费 | 免费额度有限 | 免费 | 免费 |
| 代码合规 | ✅ 内网 | ✅ | ✅ | ❌ 公司项目禁用 |

**我的推荐**：
- 公司项目 → **工蜂 + 蓝盾**（你已有 `push_kb_deploy` 那套经验，复用即可）
- 创业项目 → **CODING**（自带 CI，且和腾讯云开发同账号体系，`miniprogram-ci` 接起来最顺）

### 分支策略（对齐你现有习惯）

```
main        ← 与线上版本一致，只接受合入，不直接提交
develop     ← 集成分支
feature/*   ← 功能分支（如 feature/renderer、feature/cdn-manifest）
hotfix/*    ← 线上紧急修复
tag v1.0.0  ← 每个提审版本打 tag
```

流程沿用你的：`pull master → 切 feature 分支 → 开发提交 → 推送 → 你手动合入`。

### CI：用 `miniprogram-ci` 自动上传

微信官方命令行工具，绕开开发者工具手动点上传：

```bash
npm i -g miniprogram-ci

# 上传（提审用）
miniprogram-ci upload \
  --pp ./miniprogram \
  --pkp ./ci/private.key \
  --appid wxxxxxxxxxxxxx \
  --uv 1.0.0 \
  -r 1 \
  --enable-es6 true \
  --upload-package-option ""

# 预览（生成二维码，测试用）
miniprogram-ci preview \
  --pp ./miniprogram \
  --pkp ./ci/private.key \
  --appid wxxxxxxxxxxxxx \
  --qrcode-format image \
  --qrcode-output-dest ./ci/preview.jpg
```

**密钥管理**：`private.key` 绝不入库。放 CI 的密钥管理里（蓝盾凭证 / CODING 凭据），运行时注入到 `ci/` 目录。另外微信后台那个 **IP 白名单**建议配上 CI 机器出口 IP，双重保险。

## 3. 并行路径：哪些我能先做，哪些等你

为了不浪费备案那 1~20 天，我建议这样并行：

| 时间段 | 我做的（不需要你的材料） | 你做的 |
|--------|--------------------------|--------|
