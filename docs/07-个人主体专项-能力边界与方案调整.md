### ⚠️ 关于流量主：规则信息冲突，我如实告知

我查到的信息**互相矛盾**，不敢给你确定结论：

| 来源 | 说法 |
|------|------|
| 腾讯客服官方 FAQ | 小程序累计 UV ≥ 500、无违规即可开通，**未提主体限制** |

| 第三方技术文章 | 部分写「个人可开通」，部分写「需企业认证」 |

**我的处理建议**：既然你说"业余有趣玩一下"，**直接不规划广告变现**。理由是：
1. 即便能开，UV 500~1000 的门槛对业余项目也不算低
2. 为它设计「激励视频解锁」机制会拖累体验，而广告收益大概率还不如你花的时间值钱
3. 万一规则真是个人不可用，白做

如果哪天真跑起来了想变现，那时候再考虑注册个体工商户（成本约几百元）转成企业主体，功能再补上也不迟。

## 2. 方案调整（三处）

### 调整一：变现路径整条砍掉

| 原设计 | 调整后 |
|--------|--------|
| 免费层 / 解锁层 / 会员层 三层 | **只有免费层** |
| `needUnlock` + `unlockAdUnit` 字段 | 删除 |
| 云函数 `unlockAsset` | 删除 |
| 素材「看广告解锁」 | 删除，全量免费 |

**这其实是好事**：少了广告，编辑链路更干净，用户体验更好，口碑传播更顺。业余项目靠好玩取胜，不靠变现。

### 调整二：三期 UGC 社区砍掉

个人主体做 UGC 有两个硬伤：
1. 类目上「社交-社区/论坛」「笔记」个人备案**不建议选择**，且需 ICP 证（个人办不了）
2. UGC 意味着你要承担内容审核责任，`msgSecCheck` / `imgSecCheck` 都是要调的服务，业余维护精力吃不消

**替代方案**：想扩充素材，走「用户反馈 → 你自己做 → 你审核后上新」的轻量路径。用云数据库存个 `wm_feedback` 表收集需求就行，不用做社区。

### 调整三：云函数从 5 个减到 3 个

| 云函数 | 去留 | 理由 |
|--------|------|------|
| `reportUsage` | ✅ 保留 | 埋点，驱动热榜 |
| `getWxacode` | ✅ 保留 | 角标小程序码，裂变核心 |
| `secCheck` | ✅ 保留 | **自定义文字水印**仍需要（如果你要做这个功能） |
| `unlockAsset` | ❌ 删除 | 无变现 |
| `getHotRank` | ❌ 删除 | 首版用云数据库直接查，不用单独云函数 |

> 如果你**不做自定义文字水印**，`secCheck` 也可以去掉，云函数只剩 2 个。考虑到你是业余玩，我建议首版就先不做自定义文字——**纯预设贴纸**，零审核负担、零违规风险，做得也快。等跑起来了再加。

### 调整后的一期架构（更轻）

```
端上：选图 → 选贴纸 → 拖拽调整 → 保存（全部本地完成）
云端：manifest.json 素材清单 + CDN 素材图 + 2 个云函数（埋点 / 小程序码）
```

## 3. 代码托管：Gitee 免费私有仓

**推荐 Gitee**，理由针对"个人业余项目"这个场景：

| 维度 | Gitee | CODING | GitHub | 工蜂 |
|------|-------|--------|--------|------|
| 免费私有仓 | ✅ | ✅ 额度有限 | ✅ | ✅ |
| 国内访问速度 | **快** | 快 | 不稳 | 需办公网 |
| CI/CD | 一般 | **强** | Actions 好用 | 蓝盾 |
| 学习成本 | **低** | 中 | 低 | 中 |
| 是否适合本项目 | ✅ **推荐** | 备选 | 备选 | ❌ 别用 |

**为什么不推荐工蜂**：这是个人项目，代码放公司内网仓库会带来归属问题（见下节）。不要用公司资源做个人项目。

**CI 一期不做**：业余项目不值得为它搭流水线。用微信开发者工具手动点「上传」就行，一次 30 秒。等真的频繁发版了，再上 `miniprogram-ci` 也不迟（文档 06 里脚本已备好）。

仓库建好后把地址给我，我按这个结构初始化：

```
avatar-watermark-miniapp/
├── miniprogram/          # 小程序端
├── cloudfunctions/       # 云函数
├── docs/                 # 设计文档
├── .gitignore            # ★ 忽略 private.key
└── project.config.json
```

## 5. 一个必须提醒的事（很重要，但别被吓到）

你是腾讯在职员工。虽然是个人业余项目，但有两点建议守住边界：

1. **不要用公司设备、公司网络账号、公司时间**做这个项目（用个人电脑、个人 Gitee 账号）
2. **不要引用任何公司内部代码、文档、设计资产**（这个项目一行公司代码都不会用到，很容易做到）

不用过度紧张——一个头像水印工具和你的本职工作（福利中心金币系统）毫无关联，正常做就行。但这两条守住，后面就不会有说不清的地方。

另外素材版权那条依然是硬要求：**用自绘图形 + 通用文案**，别碰品牌 logo。个人主体被投诉侵权的容错空间比企业还小。
