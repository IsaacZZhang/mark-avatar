# 04 · 性能 · 合规 · 增长

## 1. 性能目标与手段

工具型小程序的生死线是「打开到出图」的时长。定死指标：

| 指标 | 目标 | 手段 |
|------|------|------|
| 主包体积 | **< 1.2MB** | 素材走 CDN；不引第三方 UI 库；图标用 iconfont 或 SVG |
| 冷启动首屏可见 | **< 1.5s** | `onLaunch` 只做云开发初始化 + dpr 缓存，素材清单异步拉取 |
| 水印应用响应 | **< 300ms** | 素材图本地缓存命中；预览档 540px 渲染 |
| 导出耗时 | **< 800ms** | 底图先 `wx.compressImage` 压到长边 ≤ 1080 |
| 手势帧率 | **≥ 50fps** | 手势期间不 `setData`；低分辨率预览档 |

### 具体优化项

1. **底图压缩前置**：用户从相册选的原图动辄 4000px，直接进 canvas 会吃爆内存。进编辑器前统一 `wx.compressImage({ quality: 80 })` 压到长边 1080。
2. **跳过分包预下载**：首版只有单包，别配 `preloadRule`，省资源。
3. **setData 粒度**：编辑器页面只 `setData` 图层数量、当前选中态这类小字段；渲染状态全放 canvas 侧。
4. **图片本地缓存**：素材图下载后落盘，用 `FileSystemManager` 管理，LRU 上限 20MB，超出清理最久未用。
5. **按需渲染**：分类切换时只预下载当前分类的封面图，素材大图等用户点击时再下（配合 loading 骨架）。

## 2. 合规红线（决定能否一次过审）

这一节比技术方案更重要——**审核被拒一次就多花 3~7 天**。

| # | 红线 | 风险 | 正确做法 |
|---|------|------|----------|
| 1 | **用户隐私保护指引** | 未配置将无法调用相册/头像等接口 | `app.json` 配 `"__usePrivacyCheck__": true`，并在 mp 后台「用户隐私保护指引」中声明：相册（写入）、相册（读取）、头像昵称。首次调用走 `wx.requirePrivacyAuthorize` |
| 2 | **类目选择** | 类目与服务内容不符直接拒 | 选「工具 → 图片处理」或「工具 → 头像制作」。不要用「社交」「电商」 |
| 3 | **诱导分享** | 强制分享才能保存，必拒 | 分享做成"保存成功后的可选动作"，绝不能是前置门槛 |
| 4 | **强制授权** | 未授权不让用，必拒 | 未选图时可先用示例图体验，选图时才触发授权 |
| 5 | **素材版权** | 用他人 logo/商标/卡通形象，投诉下架 | 素材全部原创或已授权。**"闲鱼卖掉了"这类要自绘图形 + 通用文案，不要复刻品牌视觉** |
| 6 | **名称与描述** | 含"微信官方""腾讯"等字样，必拒 | 名称避免平台词；描述不暗示官方身份 |
| 7 | **UGC 内容安全** | 用户上传素材/自定义文字含违规内容 | 必须过 `msgSecCheck`（文字）+ `imgSecCheck`（图片），走云函数云调用 |
| 8 | **流量主准入** | 未达 UV 门槛无法开通广告 | 先跑量，二期再接激励视频；广告位不能出现在首屏阻断操作 |

### 关于「更换微信头像」的说明

微信**不开放程序化更换用户头像的 API**。所以只能做引导：

```
保存成功 → "图片已存到相册" → [去微信换头像] 按钮
                              → 图文步骤：微信我 → 头像 → 右上角... → 从相册选择
```

这里别过度承诺，文案写「去微信换头像」引导，不要写「一键更换」。

## 3. 增长机制（按 ROI 排序）

| 机制 | 成本 | 预期效果 | 落地难度 |
|------|------|----------|----------|
| **① 作品角标小程序码** | 极低 | 每张图都是传播载体，闺蜜/群友看到即用 | 低（导出时右下角画码，用户可在设置里关） |
| **② 分享前后对比卡片** | 低 | 分享卡片带「原图 vs 加水印」对比，点击率高 | 中（需合成 5:4 卡片图） |
| **③ 热点素材 48h 上新** | 中（运营） | 节日/赛事期间自然流量峰值 | 低（CDN 热更已支持） |
| **④ 换头像引导页** | 低 | 提升完成率，闭环用户动机 | 低 |
| **⑤ 历史作品 / 收藏** | 中 | 提升回访，把一次性工具变成有留存 | 中 |
| **⑥ 激励视频解锁精品** | 中 | 变现 + 制造稀缺感 | 中（需流量主资质） |

### ① 角标小程序码的实现要点

```js
// 导出时在右下角画小程序码，尺寸约占底图 12%
async _drawBadge(ctx, W, H) {
  const size = W * 0.12;
  const qr = await this._load(this.badgeUrl);   // 云函数生成的 scene 码，缓存复用
  // 白底垫一层：深色背景上不加白底会扫不出来
  ctx.fillStyle = '#fff';
  roundRect(ctx, W - size - 16, H - size - 16, size, size, 6);
  ctx.fill();
  ctx.drawImage(qr, W - size - 10, H - size - 10, size - 12, size - 12);
}
```

**注意**：角标必须可关闭，放在设置里。默认开启，用户反感时关掉。不能强制。

### 裂变系数测算

保守估算：`分享率 8% × 点击率 40% × 新用户转化 60% ≈ 1.19/人`。大于 1 就能自增长，这也是为什么角标+分享卡片要优先做。

## 4. 变现路径（二期）

```
免费层：50+ 通用素材，无限次保存，带角标
   ↓ 激励视频（15s）
解锁层：精品素材包（节日限定 / 联名款），解锁后 7 天内可用
   ↓
会员层（三期）：去角标 + 去广告 + 全部素材 + 高清 4K 导出
```

**不建议做**：保存次数限制、看广告才能保存。这两种会直接摧毁工具型小程序的口碑传播。
