# 05 · 里程碑与风险清单

## 1. 四周上线排期

按"每周都能拿到一个可用版本"来排，任何一周中断都有交付物。

| 周 | 交付物 | 关键任务 | 验收标准 |
|----|--------|----------|----------|
| **W1** | **可跑通 MVP** | 云开发环境开通 · 编辑器页骨架 · Canvas 2D 引擎 · 头像/相册选图 · 10 个内置素材 · 保存到相册 | 真机上能完整走通「选图 → 加水印 → 存相册」 |
| **W2** | **素材库上线** | manifest 清单 + CDN 热更 · 三级缓存 · 分类选择器 · 手势缩放旋转 · 底图压缩 · 多水印叠加 | 不发版新增一个素材并在端上看到；手势操作不掉帧 |
| **W3** | **增长闭环** | 结果页（换头像引导）· 分享对比卡片 · 小程序码角标 · 埋点上报 · 云函数（reportUsage/getWxacode/secCheck） | 能看到素材热榜数据；分享卡片点开能带回参数 |
| **W4** | **提审与调优** | 隐私指引配置 · 类目核对 · 合规自检 · 真机矩阵测试 · 热点素材储备 · 提审 | 一次过审；iOS/Android 各 3 个机型无崩溃 |

### 真机测试矩阵（必测）

| 维度 | 覆盖 |
|------|------|
| 系统 | iOS 15+ / Android 10+（含鸿蒙兼容层） |
| 机型档位 | 高端（iPhone 15 / 小米 14）+ 低端（红米 Note 系列，重点测内存与耗时） |
| 微信版本 | 最近 2 个大版本 + 最低支持基础库 |
| 底图形状 | 正方形头像 / 超宽横图 / 超长竖图 / 极小图（<200px）/ 极大图（>4000px） |
| 网络 | 弱网（清单拉取失败降级）/ 断网（内置素材仍可用） |

## 2. 风险登记表

| ID | 风险 | 概率 | 影响 | 应对 |
|----|------|------|------|------|
| R1 | **审核被拒**（类目/隐私指引/诱导分享） | 中 | 高（+3~7 天） | W3 就做合规自检清单；提审前用体验版跑一遍隐私协议弹窗 |
| R2 | **素材版权投诉** | 中 | 高（下架） | 素材全部原创；建立素材上线审核 checklist；"卖掉了"类走自绘 |
| R3 | **低端机 OOM 闪退** | 中 | 中 | 底图强制压缩到 1080；单会话最多叠加 5 层；catch OOM 后降级到 720 导出 |
| R4 | **Canvas 导出黑屏**（部分安卓） | 中 | 高 | 绘制期间保持 canvas 在可视区；真机矩阵覆盖；提供"重绘一次"兜底按钮 |
| R5 | **用户用完即走，无留存** | 高 | 中 | 角标裂变 + 热点素材周更 + 历史作品；接受工具型小程序天然低留存，靠拉新而非留存做量 |
| R6 | **热点素材来不及** | 中 | 低 | 素材生产流程前置（模板 + 换字换色），运营侧 48h 上新 |
| R7 | **云开发冷启动慢** | 低 | 低 | 云函数只在非关键路径调用（埋点/审核），出图全在端上，不受影响 |

## 3. 待确认 TODO

这些是我在设计中做了假设、需要你或业务侧拍板的事项：

| ID | 待确认项 | 我的默认假设 | 影响 |
|----|----------|--------------|------|
| **T1** | 是否已有小程序主体（企业/个人）？个人主体**无法开通流量主**，变现路径要砍掉 | 假设企业主体 | 影响 D4 变现方案；个人主体则只做免费+裂变 |
| **T2** | 「相册写入」权限的隐私指引是否已提交审核？ | 假设未配置，W3 处理 | 未配置则保存功能不可用，直接阻塞 P0 |
| **T3** | 素材由谁生产？有无设计资源？ | 假设有 1 名设计，首版 50 个素材 | 无设计则需采购或改用纯文字水印方案（成本低很多） |
| **T4** | 是否需要"自定义文字水印"？需要则必须接 `msgSecCheck` | 假设需要（P1） | 影响云函数与审核材料 |
| **T5** | 目标用户画像？是泛人群还是垂直（如二手卖家、球迷） | 假设泛人群 + 热点驱动 | 影响素材库分类设计与冷启动渠道 |
| **T6** | 冷启动流量从哪来？（朋友圈投放 / 社群 / 公众号导流） | 假设纯自然 + 裂变 | 若投放，需提前做落地页参数与渠道归因埋点 |

## 4. 上线 Checklist

提审前逐条勾：

- [ ] `app.json` 已配 `__usePrivacyCheck__: true`
- [ ] mp 后台已提交并**通过**用户隐私保护指引（含相册写入/读取、头像昵称）
- [ ] 小程序类目为「工具 → 图片处理 / 头像制作」
- [ ] 保存流程无强制分享、无强制授权拦截
- [ ] 所有素材已过版权自查（无 logo / 商标 / 未授权 IP）
- [ ] 名称与简介不含"微信""官方"等违规词
- [ ] 断网状态下内置素材仍可正常使用
- [ ] 低端机（红米 Note）走完主流程无闪退，导出 < 1s
- [ ] 小程序码角标可在设置中关闭
- [ ] 云函数超时与降级已验证（杀掉云函数后仍能出图）
- [ ] 埋点数据可在云数据库中看到
