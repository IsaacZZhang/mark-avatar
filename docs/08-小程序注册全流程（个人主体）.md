# 08 · 小程序注册全流程（个人主体）

> 照着做即可，全程 **0 元**。核心目标只有一个：**拿到 AppID，并把备案提交出去**。
> 备案是唯一的长周期项，注册当天就能完成，所以顺序是「先注册 → 立刻提备案 → 备案审核期间补其他」。

---

## 时间线总览

```
Day 0   ① 注册账号（30 分钟）→ 拿到 AppID
        ② 立刻提交 ICP 备案（30 分钟）→ 进入审核队列
        ─────────────────────────────────
Day 1~2  平台初审（1~2 工作日）→ 接听 0755 回访电话
Day 2    工信部短信核验（★ 24 小时内必须完成，否则作废重来）
Day 3~25 通管局审核（1~20 工作日）
        ─────────────────────────────────
Day N    备案号下发 → 提交代码审核 → 发布
```

**并行**：Day 0~N 期间正常开发，体验版和真机调试不受备案影响。

---

## 阶段一：注册账号（30 分钟）

### 1.1 先备好这三样

| 材料 | 要求 | 常见坑 |
|------|------|--------|
| **邮箱** | 必须**未注册过**微信公众平台、开放平台、企业号，且**未绑定过个人微信号** | 用 QQ 邮箱最稳，别用已经绑过公众号的 |
| **身份证** | 18 岁以上中国大陆居民 | 一个身份证最多注册 **5 个**小程序，用掉不退 |
| **手机号** | 本人实名 | 一个手机号最多注册 **5 个** |

> 每个小程序都要用**独立的邮箱**，如果你打算以后多做几个，提前规划邮箱。

### 1.2 操作步骤

1. 打开 [mp.weixin.qq.com](https://mp.weixin.qq.com) → 右上角「**立即注册**」
2. 选择账号类型 →「**小程序**」
3. 填邮箱 + 密码 → 去邮箱查收激活邮件 → 填 **6 位验证码**
4. 选择小程序类目 → 选「**其他**」（工具类走这个；小游戏类目一旦选定不可改）
5. 主体类型 →「**个人**」
6. 填主体信息：姓名、身份证号、手机号 → 短信验证码
7. **微信扫码验证身份** —— ⚠️ **扫这个码的微信号就是「管理员」**，后面人脸核身、接审核电话都用这个号，建议用你最常用的微信
8. 注册成功 → 点「前往小程序」进入后台

### 1.3 立刻拿 AppID

后台左侧：**开发 → 开发管理 → 开发设置** → 复制 **AppID**（`wx` 开头，18 位）

把它发给我，我填进 `project.private.config.json`（这个文件已被 gitignore，不会进公开仓库）。

## 阶段二：完善基本信息（20 分钟）

**设置 → 基本设置**

| 项 | 填什么 | 注意事项 |
|----|--------|----------|
| **名称** | 2~20 字符，全局唯一 | ⚠️ 见下方「个人主体名称禁用词」，**先想 3~5 个备选** |
| **头像** | 1024×1024 PNG | 不能有圆角透明，会自动裁成圆形 |
| **简介** | 一句话说明 | 不写「一键换头像」（做不到），写「给头像加有趣水印」 |
| **服务类目** | **工具 → 图片/文字处理** | 最多 5 个，我们只选这 1 个 |

### ⚠️ 个人主体名称禁用词（备案会被拦）

个人主体名称**不能**出现这些类型，否则备案入口直接提示「昵称包含前置审批相关内容，请修改」：

| 类型 | 禁用示例 |
|------|---------|
| 企业/单位名义 | XX公司、XX集团、商厦、商城、商贸 |
| 国家公共事务 | 监管、政府、政务 |
| 前置审批领域 | 新闻、金融、医药、教育、培训、宗教、直播、出版、网约车、医疗器械 |
| 超出个人经营范围 | 商城、商贸、批发零售 |

✅ 安全示例：「头像水印铺」「水印相机酱」「头像加点料」「一键水印」—— 口语化、带工具属性、无行业敏感词。

## 阶段三：ICP 备案（提交 30 分钟，审核 1~20 工作日）

**入口**：设置 → 小程序备案 → 去备案（或首页顶部横幅「去备案」）

### 3.1 备案五个环节

| 环节 | 你要做什么 | 时长 |
|------|-----------|------|
| ① 填写备案信息 | 主体信息 + 负责人信息 + 小程序信息 + **人脸核身** | 30 分钟 |
| ② 平台初审 | 等，**保持电话畅通** | 1~2 工作日 |
| ③ 工信部短信核验 | ⚠️ **24 小时内完成**，否则自动驳回 | 24 小时窗口 |
| ④ 通管局审核 | 等，注意接听核实电话 | 1~20 工作日 |
| ⑤ 备案成功 | 拿到备案号 | — |

### 3.2 填写环节的四个坑（照着避）

**坑 1：通讯地址必须精确到门牌号**
填写「省+市+县区+乡镇街道+**具体门牌号**」（如 X 小区 X 栋 X 单元 X 号）。填到小区就停会**被驳回**。
- 身份证地址与备案省份不一致时，需额外提供居住证/暂住证 —— 涉及省份：吉林、上海、江苏、浙江、安徽、山东、湖北、广东、四川、贵州、云南

**坑 2：人脸核身必须用「管理员微信」扫**
用**注册时扫码的那个微信号**做人脸核身。用别的号扫会报「实名验证失败」。
- 环境要求：**纯白背景**、光线充足、不戴帽子眼镜、表情自然

**坑 3：服务内容不能选经营性质**
个人主体**禁止**选「批发和零售业-零售批发」这类经营性内容。
- ✅ 我们选：工具类 / 信息服务类相关的非经营项（按页面实际可选列表，选最接近「图片处理工具」的那一项）
- 前置审批项：选「**以上都不涉及**」

**坑 4：工信部短信核验 24 小时窗口**
平台初审通过后，工信部会用 **12381** 给你发验证码短信。

> ⚠️ **这是最容易翻车的一步**。24 小时内没核验 → 备案被系统自动驳回 → 从头再走一遍流程。
> 只有两次重发机会。提交后那两天务必留意手机，别让短信过期。

### 3.3 审核期间的电话（务必接）

| 号码 | 来源 | 说明 |
|------|------|------|
| **0755-3291xxxx** / **0755-3656xxxx** | 微信平台审核回访 | 漏接可能被驳回 |
| **12381** | 工信部短信核验 | 见上，24 小时内处理 |
| 各省管局号码 | 通管局核实 | 备案省份属地号码 |

## 阶段四：开发设置（5 分钟）

**开发 → 开发管理 → 开发设置**

| 项 | 操作 |
|----|------|
| **AppID** | 复制发我（已拿） |
| **AppSecret** | 生成后**自己保存好**。我们用云开发免鉴权云调用，**代码里不需要它**，千万别提交到公开仓库 |
| **服务器域名** | 一期不用配（云存储域名后续在开发者工具里一键加入白名单即可） |
| **小程序代码上传密钥** | 点「生成」下载 `private.key` + 配 IP 白名单。⚠️ **绝不入库** |

## 阶段五：用户隐私保护指引（★ P0，不做保存功能用不了）

**设置 → 用户隐私保护指引** → 提交审核（1~3 工作日）

必须勾选这三项：

- [x] **相册（写入）** —— 保存头像到相册
- [x] **相册（读取）** —— 用户从相册选图
- [x] **头像、昵称** —— 头像填写能力

代码侧已配好：`app.json` 里 `"__usePrivacyCheck__": true`。

> 这个不通过，用户点保存会直接失败。它和备案是**两条独立的审核通道**，可以并行提交，建议 Day 0 一起提。

## 阶段六：开通云开发（10 分钟，可延后）

微信开发者工具 → 工具栏「**云开发**」→ 开通 → 创建环境 → 复制**环境 ID**

有了环境 ID 发我，我填进 `app.js` 的 `CLOUD_ENV`。一期不填也能跑（内置素材离线可用）。

## 常见驳回原因速查

| 驳回原因 | 怎么改 |
|---------|--------|
| 通讯地址不详细 | 补到门牌号 |
| 名称含前置审批关键词 | 换名，避开禁用词表 |
| 人脸核身实名验证失败 | 用**管理员微信号**重新扫，白底 |
| 身份证与备案省份不一致 | 补居住证/暂住证 |
| 服务内容选了经营性质 | 改成非经营性工具类 |
| 24 小时未短信核验 | 只能重新提交，从头再来 |
| 未接听 0755 回访电话 | 保持畅通，漏接就等驳回后重提 |
