# 09 · 本地预览页说明（不用装开发者工具就能 review）

## 为什么要有这个东西

小程序的开发反馈链路有个天然断点：**想看效果就得开微信开发者工具**，而开发者工具要装、要登录、要导项目。
做一个「改一行代码 → 立刻看到」的短反馈环，方向就能随时纠，不会写了两周才发现水印默认位置丑得不行。

所以做了 `preview/index.html`：单文件、零依赖、双击就开。

## 它和真机的关系

| 维度 | 预览页 | 真机 |
|------|--------|------|
| 渲染逻辑 | **同构**：`drawCover` / `drawLayer` / `hitTest` / `pinch` 与 `engine/` 一一对应 | `engine/` 本体 |
| 素材 | 内嵌 base64，读的是 `assets/stickers/*.png` | 同一批文件 |
| 导出 | 离屏 1080 + jpg 0.92，逻辑一致 | 同 |
| 坐标系 | 归一化 0~1，一致 | 一致 |
| Canvas API | Web Canvas 2D | 小程序 Canvas 2D（`type="2d"`） |

**它验证不了的三件事**，只能真机测：

1. `chooseAvatar` 头像填写能力 —— 真机独占，浏览器模拟不了
2. 低端安卓的实际帧率 —— Web Canvas 与小程序双线程模型性能特征不同
3. 保存相册的授权弹窗链路（`getSetting` → `showModal` → `openAppAuthorizeSetting`）

## 怎么用

```
双击 preview/index.html
```

| 想干什么 | 怎么操作 |
|---|---|
| 看水印效果 | 点下方素材条，分类 tab 可切「搞笑 / 心情 / 生活」 |
| **看自己的真实头像** | 点「换底图」，或把图片直接拖到画布上 |
| 移动 / 缩放 / 旋转 | 鼠标拖 = 移动，滚轮 = 缩放，右侧控制条 = 缩放/旋转/透明度 |
| 看结果页 | 点「做好了」→ 成品图 + 换头像三步引导 + 存相册 → 点「继续调整」可退回 |
| 看导出清晰度 | 结果页点「保存到相册」，下载 1080×1080 jpg |

## review 时重点看这几处

这几处是最容易「做完才发现不对」的地方，改它们的代码成本很低，改晚了的返工成本很高：

1. **水印出厂位置** —— `config/templates.js` 里每个素材的 `layout`（`cx` / `cy` / `scale`）。默认是我拍的，你觉得压脸还是压背景，现在说。
2. **水印视觉风格** —— 现在是脚本生成的占位图（描边圆形/方形贴纸）。正式素材要不要换成印章感、手写感、还是表情包感，决定了整个产品调性。
3. **结果页三步引导文案** —— 微信不开放自动换头像，这步只能手动。这三句话是转化咽喉：写不清楚，用户存了图也不会去换。
4. **角标小程序码** —— `app.js` 的 `showBadge`。带上能拉新，但会挡住头像一角。默认开，你觉得碍事就关。

## 重新生成

改了素材或渲染逻辑后重跑一次，预览页会自动同步：

```bash
python3 tools/gen_preview.py
```

脚本读 `miniprogram/config/templates.js` 的清单和 `miniprogram/assets/stickers/` 的图，把它们 base64 内嵌进 HTML。所以 155KB 是素材撑起来的，不是代码。

## 它不进小程序包

`preview/` 在项目根目录，不在 `miniprogramRoot` 里，不会被打包，不影响 2MB 限额。
